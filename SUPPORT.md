# Support

Start with the [README](README.md), [CI guide](docs/CI.md) and [implementation plan](docs/implementation-plan.md).

Use [GitHub issues](https://github.com/i098/open-loops/issues) for non-sensitive questions, bug reports and feature requests. Include the commit, operating system, browser or command used, reproduction steps and the first relevant error. Remove secrets and personal data before posting.

Report vulnerabilities through the process in [SECURITY.md](SECURITY.md), not a public bug report.

## Limits

This is a browser prototype with a native implementation plan. There is no native installer, live connector support, production service or uptime commitment. A proposed feature is not an available integration.

Named support maintainers, response times and any future discussion channel are **TBD**. GitHub Discussions is not assumed to be configured. No paid support or SLA is offered by this document.
